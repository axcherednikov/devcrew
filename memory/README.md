# DevCrew project memory

Place durable, project-specific lessons in the memory directory configured for this repository. Keep one-off task facts in task cards and do not treat this directory as built-in model memory.

Explicit durable engineering requirements may be indexed in `engineering-requirements.json` by the configured memory workflow. New requirements belong in that registry; requirements owned by existing project instructions, documentation, or tool configuration must remain reference-only. One-off task facts stay in task/session artifacts.
