# Сообщение коммита

`type(task-id-or-area): Краткий результат изменения`

Одна строка с завершённым результатом. Используйте язык и формат проекта. Примеры:

```text
fix(DEMO-101): Устранены дубликаты в результатах поиска
feat(DEMO-102): Добавлен фильтр по типу файла в поиске
refactor(search): Упрощена сортировка результатов
docs(api): Исправлено описание параметров поиска
feat(api)!: Удалён устаревший формат ответа поиска
```
