# Brief misses log

Copy this [template](misses-log.md), or its [Russian version](ru/misses-log.md), to `brief-misses.md` in the target project's configured memory directory. Add entries to the project copy. Leave the installed plugin unchanged. The log gives `retro.md` a cross-session record of low-cost type C misses: a class of problem the existing checks missed **once**. A second miss of the same class warrants a check.

At each retrospective, look for an active row of the same class. On a second occurrence, add a check and close the row. On a first occurrence, start a new row.
