# Шаблоны результата

Включите только разделы для запрошенных аудиторий. Полная передача начинается с личной сводки, затем идут разделы для QA, команды клиентского приложения и заказчика. Каждый раздел для внешней аудитории должен быть готов к отправке отдельно. Личная сводка предназначена только для пользователя DevCrew.
