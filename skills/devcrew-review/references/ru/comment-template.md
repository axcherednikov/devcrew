# Построчное замечание в GitHub или GitLab

Обязательный шаблон:

```text
Проблема:
...

Что исправить:
...

Как выявлено:
...
```

Пример для замечания, подтверждённого статическим анализом:

```text
Проблема:
При ошибке API возвращается пустой результат без ошибки, поэтому вызывающий код не отличит сбой от отсутствия данных.

Что исправить:
Верни исходную ошибку или добавь её в обёртку через %w.

Как выявлено:
Статический анализ ветки обработки ошибки в src/service.go:37: при err != nil выполняется return nil, nil. Тесты не запускались.
```
