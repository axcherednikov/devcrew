# Состояние сессий DevCrew

Сохраняйте снимки сессий и материалы для передачи задач в каталоге сессий, настроенном для этого репозитория. Указывайте ревизию Git, изменённые файлы, проверки, результаты, открытые вопросы и следующее действие.

По умолчанию используется игнорируемый каталог `.codex/sessions/`. Эти сведения нужны для восстановления рабочей сессии. В память, документацию и правила проекта переносите только проверенные знания, которые пригодятся в дальнейшем. Историю сессии храните в одном месте.
