# Правила области проекта

Этот документ — обычная справка, не автоматически подключаемое правило Codex. Оркестратор явно читает его перед делегированием релевантной работы и передаёт исполнителю путь и область применения.

Для каждой области укажи фактические каталоги, проверенный источник требования, само требование и подходящую проверку. Не переноси правила чужого проекта. Если проект использует вложенные `AGENTS.md`, следуй его существующей структуре; не добавляй второй механизм инструкций без необходимости.
