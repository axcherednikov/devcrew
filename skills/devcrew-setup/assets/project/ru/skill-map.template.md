# Карта skills

Перечисли доступные в текущей сессии skills, их назначение и точные пути. Пакет включает devcrew-task, devcrew-setup, devcrew-brief, devcrew-review, devcrew-session, devcrew-small-talk. Внешние skills не считаются установленными по одному упоминанию. Не записывай секреты или учётные данные.
