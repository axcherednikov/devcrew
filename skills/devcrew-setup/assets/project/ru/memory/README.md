# Память проекта DevCrew

В каталоге памяти, настроенном для этого репозитория, сохраняйте выводы о проекте, которые пригодятся в следующих задачах. Факты об одной задаче фиксируйте в её карточке. Доступ модели к содержимому этого каталога требует явного чтения файлов.

Настроенный процесс работы с памятью может регистрировать явные долговременные инженерные требования в `engineering-requirements.json`. Добавляйте в реестр новые требования. Для требований, уже закреплённых в инструкциях проекта, документации или конфигурации инструментов, сохраняйте только ссылки на источники. Разовые сведения оставляйте в материалах задачи или сессии.
