# Состояние задач DevCrew

Храните список задач и их карточки в каталоге задач, настроенном для этого репозитория. В карточке указывайте статус, границы задачи, критерии приёмки, замечания и ссылки на рабочие материалы.

По умолчанию используется игнорируемый каталог `.codex/tasks/`. Для каждой задачи создайте подкаталог с её идентификатором или кратким именем. В нём хранятся постановка, план, черновики, отчёт о реализации и материалы передачи. В долговременной документации кратко фиксируйте подтверждённое поведение и решения, в памяти — выводы для повторного использования, в правилах — принятые инварианты проекта. Полный пакет задачи остаётся в её подкаталоге.

Для новой карточки используйте `card.template.md`. Обновляйте её структурированное состояние при переходе между этапами и перед передачей работы. Если в старой карточке нет нужных полей, добавьте их при продолжении задачи, сохранив историю и соглашения проекта. Отчёты автоматических проверок храните в настроенном каталоге проверок и добавляйте ссылки на них в карточку.
