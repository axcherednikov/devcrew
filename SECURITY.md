# Reporting a vulnerability

Use the repository host's private vulnerability-reporting feature when available. On GitHub, open **Security → Report a vulnerability**. If private reporting is unavailable, ask the maintainer for a private contact in an issue without posting technical details. Include the affected release, platform and user impact in the private report. Remove credentials, prompts, customer data and local check logs.

## Сообщить об уязвимости

Используйте приватную отправку отчётов на площадке репозитория. На GitHub откройте **Security → Report a vulnerability**. Если функция недоступна, запросите у сопровождающего приватный контакт через issue без технических подробностей. В приватном сообщении укажите версию, платформу и последствия для пользователя. Удалите учётные данные, сообщения из чатов, клиентские данные и локальные журналы проверок.
